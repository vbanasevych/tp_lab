# SIPL Language Toolkit

Інструментарій для мови програмування **SIPL**, реалізований на Java 26.
Проєкт охоплює повний цикл обробки програм: лексичний та синтаксичний аналіз, побудову типізованого AST із координатами, інтерпретацію, подійне трасування виконання та візуалізацію дерев.

## Виконані завдання та вимоги (10.0 / 10.0 балів)

### Ядро мови та виконання (6.0 балів)

* [x] **CORE-01 (0.5 б):** Формальна специфікація SIPL (машинозчитувана граматика ANTLR4, $\ge 10$ позитивних і $\ge 10$ негативних тестів).
* [x] **CORE-02 (1.5 б):** Парсер та типізоване AST з позиціями (`SourceSpan`) у вихідному тексті.
* [x] **CORE-03 (2.0 б):** Інтерпретатор SIPL (стан змінних, присвоювання `:=`, композиція `;`, `if/then/else`, `while/do`, `begin/end`, `skip`).
* [x] **CORE-04 (1.0 б):** Подієва модель виконання (`ExecutionListener`) та trace (відстеження кроків та станів).
* [x] **CORE-05 (1.0 б):** CLI інструмент на базі Picocli (команди `parse`, `check`, `run`, `trace` з підтримкою JSON).

* [x] **VIS-02 (1.0 б):** Візуалізація AST у форматах JSON/DOT та порівняння Parse Tree з AST.

## Основні можливості

* **Формальна граматика та парсер (ANTLR4):** розбір конструкцій `begin/end`, `:=`, `;`, `if/then/else`, `while/do`, `skip`, арифметичних (`+`, `-`, `*`) та логічних (`=`, `>`, `not`, `or`) виразів.
* **Типізоване AST з `SourceSpan`:** очищене абстрактне синтаксичне дерево зі збереженням позиції (рядок, колонка) кожного вузла у вихідному коді.
* **Інтерпретатор:** пряме виконання AST з керуванням станом змінних (`Map<String, Integer>`).
* **Подієве трасування (Trace):** підписка на події виконання операторів (`ExecutionListener`) та експорт історії змін стану пам'яті у формат JSON.
* **CLI-інтерфейс (Picocli):** зручна робота з файлами `.sipl` з командного рядка.
* **Візуалізація:** експорт графів Parse Tree та AST у формати `.dot` (Graphviz / SVG) і `.json` для структурного порівняння.

## Обмеження та обробка помилок

* **Область значень змінних:** усі змінні мають цілочисельний тип ($\mathbb{Z}$, представлений типом `int` у Java).
* **Неініціалізовані змінні:** відповідно до базової операційної семантики SIPL, звернення до неініціалізованої змінної повертає значення за замовчуванням `0`.
* **Захист від нескінченних циклів:** оскільки проблема зупинки є алгоритмічно нерозв'язною в загальному випадку, інтерпретатор має явний ліміт кроків виконання (`10 000` операторів). При перевищенні ліміту виконання переривається з повідомленням та прив'язкою до позиції вузла (`SourceSpan`).
* **Обсяг специфікації:** реалізовано базову імперативну мову SIPL (відповідно до Практичних робіт 1–3 посібника «Теорія програмування. Практикум», 2024). Розширення рекурсивними функціями (Практична робота 7) не входить до релізу `v1.0.0`.

## Вимоги та збірка

* **JDK 26** (або новіша)
* **Apache Maven 3.9+**

Запуск модульних тестів та перевірка проєкту:

```bash
mvn clean verify
```

Збірка виконуваного JAR-файлу:

```bash
mvn clean package
```

## Використання CLI

Запуск утиліти через зібраний JAR-архів:

```bash
java -jar target/tp_lab-1.0.0-jar-with-dependencies.jar <КОМАНДА> <ФАЙЛ.sipl>
```

### Доступні команди

| Команда | Опис |
| :--- | :--- |
| `check <file>` | Перевірити синтаксичну коректність файлу без запуску |
| `parse <file>` | Розібрати файл і вивести інформацію про кореневий вузол AST |
| `run <file>` | Виконати програму та вивести фінальний стан усіх змінних |
| `trace <file>` | Виконати програму з покроковим виводом станів пам'яті у JSON |
| `vis-parse <file> [-f dot\|json\|both]` | Згенерувати візуалізацію Parse Tree у DOT та/або JSON |
| `vis-ast <file> [-f dot\|json\|both]` | Згенерувати візуалізацію AST у DOT та/або JSON |

## Приклади програм на SIPL

У директорії `examples/` містяться готові приклади програм:

* `examples/factorial.sipl` — обчислення факторіала числа ($5! = 120$).
* `examples/gcd.sipl` — пошук найбільшого спільного дільника (алгоритм Евкліда).
* `examples/fibonacci.sipl` — обчислення $n$-го числа Фібоначчі з використанням розгалужень та логічних заперечень.

Приклад запуску (`examples/factorial.sipl`):

```text
begin
    x := 5;
    res := 1;
    while x > 0 do
    begin
        res := res * x;
        x := x - 1
    end
end
```

Команда виконання (`run`):

```bash
java -jar target/tp_lab-1.0.0-jar-with-dependencies.jar run examples/factorial.sipl
```

Очікуваний результат:

```text
Виконання завершено успішно.
Фінальний стан пам'яті (змінні): {res=120, x=0}
```
