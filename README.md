# SIPL Language Toolkit

Інструментарій для мови програмування **SIPL** (*Simple Imperative Programming Language*), реалізований на Java 26.
Проєкт охоплює повний цикл обробки програм: лексичний та синтаксичний аналіз, побудову типізованого AST із координатами, інтерпретацію, подійне трасування виконання та візуалізацію дерев.

## Основні можливості

- **Формальна граматика та парсер (ANTLR4):** розбір конструкцій `begin/end`, `:=`, `;`, `if/then/else`, `while/do`, `skip`, арифметичних (`+`, `-`, `*`) та логічних (`=`, `>`, `not`, `or`) виразів.
- **Типізоване AST з `SourceSpan`:** очищене абстрактне синтаксичне дерево зі збереженням позиції (рядок, колонка) кожного вузла у вихідному коді.
- **Інтерпретатор:** пряме виконання AST з керуванням станом змінних (`Map<String, Integer>`).
- **Подієве трасування (Trace):** підписка на події виконання операторів (`ExecutionListener`) та експорт історії змін стану пам'яті у формат JSON.
- **CLI-інтерфейс (Picocli):** зручна робота з файлами `.sipl` з командного рядка.
- **Візуалізація:** експорт графів Parse Tree та AST у формати `.dot` (Graphviz / SVG) і `.json` для структурного порівняння.

## Вимоги та збірка

- **JDK 26** (або новіша)
- **Apache Maven 3.9+**

Запуск модульних тестів та перевірка проєкту:

```bash
mvn clean verify
```

Збірка виконуваного JAR-файлу:

```bash
mvn clean package
```

## Використання CLI

Запуск утиліти через зібраний JAR-архів:

```bash
java -jar target/tp_lab-1.0.0-jar-with-dependencies.jar <КОМАНДА> <ФАЙЛ.sipl>
```

### Доступні команди

| Команда | Опис |
| :--- | :--- |
| `check <file>` | Перевірити синтаксичну коректність файлу без запуску |
| `parse <file>` | Розібрати файл і вивести інформацію про кореневий вузол AST |
| `run <file>` | Виконати програму та вивести фінальний стан усіх змінних |
| `trace <file>` | Виконати програму з покроковим виводом станів пам'яті у JSON |
| `vis-parse <file> [-f dot\|json\|both]` | Згенерувати візуалізацію Parse Tree у DOT та/або JSON |
| `vis-ast <file> [-f dot\|json\|both]` | Згенерувати візуалізацію AST у DOT та/або JSON |

## Приклад програми на SIPL

Створи файл `factorial.sipl`:

```text
begin
    x := 5;
    res := 1;
    while x > 0 do
    begin
        res := res * x;
        x := x - 1
    end
end
```

Запуск виконання (`run`):

```bash
java -jar target/tp_lab-1.0.0-jar-with-dependencies.jar run factorial.sipl
```

Очікуваний результат:

```text
Виконання завершено успішно.
Фінальний стан пам'яті (змінні): {x=0, res=120}
```
